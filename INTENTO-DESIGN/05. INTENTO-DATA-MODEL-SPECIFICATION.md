**Product:** Intento AI Communication Platform

---

# 1. Doel van dit document

Dit document beschrijft het gegevensmodel van Intento.

Het doel is om vast te leggen:

* welke gegevens bestaan;
* welke relaties bestaan;
* welke gegevens permanent worden opgeslagen;
* welke gegevens tijdelijk zijn;
* welke gegevens beschikbaar zijn voor de AI.

---

# 2. Ontwerpprincipes

## 2.1 Gebruiker is eigenaar van persoonlijke gegevens

Persoonlijke communicatiegegevens behoren toe aan de gebruiker.

Een organisatie beheert toegang, maar is niet de eigenaar van de communicatie-identiteit.

---

## 2.2 Minimale gegevensopslag

Intento bewaart alleen gegevens die nodig zijn voor:

* communicatie;
* personalisatie;
* verbetering van de ervaring.

---

## 2.3 Context is gescheiden

De AI krijgt geen onbeperkte toegang tot alle gegevens.

Elke AI-aanroep krijgt alleen:

* noodzakelijke persoonlijke context;
* actuele gesprekcontext;
* toegestane voorkeuren.

# 4. Organization

## Beschrijving

Een Intento omgeving.

Voorbeelden:

* zorginstelling;
* familieomgeving;
* persoonlijke omgeving.

---

## Velden

```json id="5kn6tc"
{
  "id": "org_001",
  "name": "Familie omgeving",
  "type": "family",
  "createdAt": "date"
}
```

---

## Eigenschappen

Een organisatie kan hebben:

* meerdere gebruikers;
* meerdere begeleiders;
* meerdere beheerders.

# 19. Export / Import profiel

## Doel

Gebruiker kan identiteit meenemen.

Export bevat:

* communicatieprofiel;
* persoonlijke context;
* voorkeuren;
* instellingen.

Niet standaard:

* accountgegevens;
* organisatiegegevens.

---

# 20. Data die NIET automatisch opgeslagen wordt

Intento slaat niet automatisch op:

* aannames van AI;
* afgewezen boodschappen;
* onzekere voorspellingen;
* irrelevante gesprekken.

---

# 21. Samenvatting

Het Intento datamodel bestaat uit:

```text id="9qf4wz"
Gebruiker

+

Persoonlijke context

+

AAC kennis

+

Gesprekscontext

+

AI voorkeuren

+

Beheerstructuur
```

De kern:

De AI kent de gebruiker steeds beter, maar alleen op basis van informatie die de gebruiker of vertegenwoordiger toestaat.
