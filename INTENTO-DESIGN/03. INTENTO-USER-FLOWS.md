**Document:** 03_User_Flows.md
**Versie:** 0.1
**Status:** Concept
**Product:** Intento AI Communication Platform

---

# 1. Doel van dit document

Dit document beschrijft de belangrijkste gebruikersstromen binnen Intento.

Het doel is om vast te leggen:

* hoe gebruikers communiceren;
* hoe begeleiders ondersteunen;
* hoe de AI keuzes maakt;
* welke stappen en beslissingen plaatsvinden.

---

# 2. Algemene communicatieflow

De basisflow van Intento:

```text
Start communicatie

        ↓

AI bepaalt mogelijke intentie

        ↓

AI toont pictogramkeuzes

        ↓

Gebruiker kiest één pictogram

        ↓

AI verwerkt keuze + context

        ↓

Nieuwe opties bepalen

        ↓

Voldoende zekerheid?

        ↓

Ja → boodschap voorstellen

Nee → volgende vraag stellen

        ↓

Gebruiker bevestigt of corrigeert
```

---

# 3. Flow: gebruiker wil zelf iets vertellen

## Doel

De gebruiker wil zelfstandig een boodschap maken zonder vooraf bepaalde vraag.

---

## Start

Gebruiker opent Intento.

Scherm:

```
Wat wil je vertellen?

🗣 Iets zeggen
❤️ Hoe ik mij voel
🤕 Er is iets aan de hand
❓ Een vraag stellen
🎯 Iets willen
```

---

## Stap 1 — Intentie bepalen

Gebruiker kiest:

```
🎯 Iets willen
```

AI-context:

```
Intentie:
Gebruiker wil waarschijnlijk een wens uitdrukken.
```

---

## Stap 2 — Algemene richting bepalen

AI toont:

```
Wat wil je?

🍽 Iets eten
🥤 Iets drinken
🚶 Iets doen
👥 Iemand zien
🏠 Ergens heen
```

---

## Stap 3 — Verfijnen

Gebruiker kiest:

```
🚶 Iets doen
```

AI toont:

```
Wat wil je doen?

🌳 Buiten
🏠 Binnen
🎮 Spelen
📺 Kijken
```

---

## Stap 4

Gebruiker kiest:

```
🌳 Buiten
```

AI gebruikt context:

* persoonlijke voorkeuren;
* eerdere keuzes;
* bekende activiteiten.

Nieuwe vraag:

```
Wat wil je buiten doen?

🚶 Wandelen
🚲 Fietsen
🐕 Met hond
🏞 Naar een plek
```

---

## Stap 5

Gebruiker kiest:

```
🐕 Met hond
```

AI genereert:

```
Ik denk dat je wilt zeggen:

"Ik wil buiten wandelen met mijn hond."

Klopt dat?

✅ Ja
❌ Nee
```

---

## Resultaat

Bij JA:

* boodschap is afgerond;
* boodschap kan worden getoond;
* eventueel uitgesproken worden.

Bij NEE:

* correctieflow starten.

# 7. Flow: begeleider ondersteunt bediening

## Situatie

De gebruiker kan cognitief kiezen maar motorisch niet bedienen.

---

Proces:

1. AI toont keuzes.
2. Gebruiker geeft keuze aan.
3. Begeleider tikt keuze aan.
4. Intento verwerkt keuze alsof gebruiker deze heeft gekozen.

---

Regel:

De begeleider voert alleen de handeling uit.

De betekenis blijft afkomstig van de gebruiker.

---

# 8. Flow: AI weet het niet zeker

## Situatie

AI heeft meerdere mogelijkheden.

Voorbeeld:

```
Wandelen 45%
Fietsen 35%
Bezoek 20%
```

---

Prioriteit:

Niet direct JA/NEE.

Eerst:

```
Wat wil je buiten doen?

🚶 Wandelen
🚲 Fietsen
👥 Bezoek
```

---

Pas bij voldoende zekerheid:

```
Ik denk dat je wilt wandelen.

Klopt dat?

✅ Ja
❌ Nee
```

# 9. Flow: gebruiker corrigeert AI

## Situatie

AI maakt verkeerde inschatting.

---

Gebruiker:

```
❌ Nee
```

---

AI:

Analyseert:

```
Mogelijke fout:

Laatste keuze:
wandelen

Alternatieven:
bezoeken
fietsen
```

---

Nieuwe vraag:

```
Wat bedoelde je?

🚶 Wandelen
👥 Bezoek
🚲 Fietsen
```

---

De AI leert:

Deze combinatie leidde niet tot juiste interpretatie.

# 10. Flow: verkeerde klik herstellen

## Situatie

Gebruiker kiest per ongeluk verkeerd.

---

Gebruiker:

```
↩ Vorige keuze
```

---

Intento:

* verwijdert laatste keuze;
* herstelt vorige context;
* toont opnieuw opties.

# 11. Flow: eerste installatie gebruiker

## Actor

Begeleider.

---

Stap 1

Account maken.

---

Stap 2

Gebruiker toevoegen.

Gegevens:

* naam;
* communicatie-instellingen;
* aantal pictogrammen;
* ondersteuningstype.

---

Stap 3

Persoonlijke wizard.

Voorbeelden:

```
Wie zijn belangrijk?

👩 Lisa
👨 Peter
🐕 Max
```

---

Stap 4

Communicatiestijl instellen.

Voorbeelden:

```
Aantal keuzes:

○ 2
○ 4
○ 6
○ 8
```

---

Stap 5

Tablet koppelen.

---

Resultaat:

Gebruiker kan starten.

# 12. Flow: persoonlijke context uitbreiden

## Trigger

AI merkt:

```
Gebruiker kiest vaak hetzelfde concept.
```

---

Mogelijkheid:

Begeleider krijgt suggestie:

```
Wil je toevoegen?

"Favoriete activiteit:
wandelen"
```

---

Begeleider kan:

* accepteren;
* aanpassen;
* weigeren.

---

# 13. Flow: einde gesprek

Na afronding:

Intento kan opslaan:

* bevestigde boodschap;
* gebruikte route;
* nieuwe voorkeur.

Niet opslaan:

* onzekere aannames;
* afgewezen voorstellen.

---

# 14. Belangrijkste UX-regels

Intento moet altijd:

* maximaal één keuze tegelijk vragen;
* grote duidelijke pictogrammen gebruiken;
* geen onnodige herhaling geven;
* fouten eenvoudig herstellen;
* gebruiker controle geven;
* begeleider ondersteunen zonder over te nemen.

---

# 15. Kernflow in één zin

De gebruiker geeft een intentie aan, de AI stelt gerichte pictogramkeuzes voor, de gebruiker verfijnt de betekenis en Intento vertaalt dit uiteindelijk naar een bevestigde persoonlijke boodschap.
